# Digifixx

Fresh Next.js App Router foundation for the Digifixx desktop admin panel.

## Getting Started

Install dependencies and run the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Application routes live under `src/app`, shared UI components live under `src/components`, and shared utilities live under `src/lib`.

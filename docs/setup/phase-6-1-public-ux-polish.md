# Phase 6.1 Public UX Polish

Phase 6.1 makes public Telegram landing pages more mobile-first and compact.

Support Line 1 and Support Line 2 are now pre-filled when creating a landing page. Admins can still edit both fields before saving. If either field is left blank, the server action saves the default copy.

The top Telegram notice bar now links to:

```text
https://telegram.org/dl
```

It opens in a new tab with `noopener noreferrer`.

Countdowns remain optional and should only be enabled for real deadlines. This phase softens the countdown UI but does not disable the Telegram CTA when the timer ends.

No Meta Pixel, Conversions API, visitor sessions, tracking events, or analytics behavior is added in this phase.
